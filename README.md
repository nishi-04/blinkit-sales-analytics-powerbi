# 🛒 Blinkit Sales Analytics Dashboard | Power BI

## 📊 Project Overview

An interactive **Power BI Sales Analytics Dashboard** developed to analyze Blinkit's sales performance, product categories, outlet characteristics, and key business KPIs.
The project transforms raw sales data into an interactive business intelligence dashboard that helps identify sales patterns, compare outlet performance, and understand product-level trends.

## 🎯 Business Objectives
- Analyze overall sales performance using key KPIs.
- Identify high-performing product categories.
- Compare sales across different outlet types and sizes.
- Analyze sales based on outlet location.
- Understand sales trends over outlet establishment years.
- Compare product performance based on fat content.
- Provide interactive filtering for business-level analysis.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPI development
- **Excel / CSV** – Source data
- **GitHub** – Project documentation and portfolio

## 📌 Key Performance Indicators
The dashboard tracks the following KPIs:

 **KPI  Description**
 Total Sales - Overall revenue generated 
 No. of Items - Total number of items analyzed 
 Average Rating - Average customer rating 
 Average Sales - Average sales per item 

## 📊 Dashboard Features

### 1. Sales Performance
Provides an overview of total sales and average sales using interactive KPI cards.

### 2. Item Type Analysis
Analyzes sales across different product categories to understand product-level performance.

### 3. Fat Content Analysis
Compares sales between different item fat-content categories.

### 4. Outlet Size Analysis
Analyzes sales across different outlet sizes such as Small, Medium, and High.

### 5. Outlet Location Analysis
Compares sales performance across different outlet location types.

### 6. Outlet Establishment Trend
Visualizes sales performance across outlet establishment years.

### 7. Outlet Type Comparison
Provides a detailed comparison of outlet types using:

- Total Sales
- Number of Items
- Average Rating
- Item Visibility
- Average Sales

## 🎛️ Interactive Filters
The dashboard includes interactive slicers that allow users to analyze specific segments based on:

- Outlet Size
- Outlet Type
- Outlet Location Type

Users can combine these filters to explore different business scenarios dynamically.

## 🧹 Data Preparation
The dataset was prepared using **Power Query** before visualization.

The data preparation process included:

- Data cleaning
- Data type validation
- Handling categorical and numerical fields
- Preparing data for analysis
- Structuring the dataset for Power BI visualization

## 🧮 DAX & Data Analysis
DAX measures were created to calculate important business metrics including:

- Total Sales
- Average Sales
- Number of Items
- Average Rating

These measures were used to create dynamic KPI cards and visualizations that respond to dashboard filters.
